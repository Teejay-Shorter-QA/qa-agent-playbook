# Rule: Keep Rules Short

This file demonstrates the shape of a rule: small, always-loaded, non-negotiable. Rules are
included in every session via `CLAUDE.md`'s `@rules/<file>.md` line, so keep each one to what a
reader needs on every single turn — anything deeper belongs in a skill instead.

**Replace this file** with your own team's short, always-true constraints. One good candidate:
whatever check you'd otherwise have to repeat as a reminder in every conversation.
